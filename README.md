A perspective-switching puzzle game created for the MDEV 26 Game Jam.

Switch between 2D and 2.5D to uncover paths, interact with objects, and solve puzzles. What exists in one perspective may disappear in the other.

Gameplay:

The game introduces its mechanics through short tutorial levels before bringing them together in a final challenge. Collect keys and unlock objects to progress. Move planks to create a traversable path. Use boxes whose presence changes with your perspective. Switch perspectives to find solutions.

Controls:

Follow the in-game tutorial prompts.

Move: WASD

Jump: SPACEBAR

Switch perspective: Q

Interact: E

Grab: G

Play

Windows: Download the Windows build, extract the ZIP, and launch the game executable.

This project was developed within a game jam deadline. The exported build has been playtested, and two issues were observed:

A locked box containing a key may disappear unexpectedly.

A vanishing box may move in depth and fall off its platform.
